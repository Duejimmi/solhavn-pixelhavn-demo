# Solhavn Mix og Pixelhavn

To hyggelige browser-spilprototyper med samme lille eventyr i to visuelle stilarter.

## Sådan spiller du

Vælg en stil, find et æg, varm det i butikken, og find bær til dit nye dyr. Brug den store handlingsknap, eller klik/tryk i verden for at gå.

Du kan skifte stil undervejs, slå lyden fra og nulstille spillet. Fremskridt bevares mellem stilarterne, mens siden er åben. En genindlæsning starter en ny prøve.

## Teknik

Statisk HTML, CSS og JavaScript. GitHub Pages udgiver main-grenens rodmappe. Ingen server eller konto er nødvendig for at spille.

3D-visningen bruger Three.js 0.186.1 under MIT-licensen; se vendor/THREE-LICENSE.txt. Hvis browseren ikke understøtter 3D, bruges pixelvisningen.
